# animation-studio
Цель проекта - спроектировать и реализовать базу данных для предметной области «Студия мультипликации», обеспечивающую хранение исходных данных о проектах, эпизодах, кадрах, этапах производства и сотрудниках, а также получение ответов на предусмотренные заданием аналитические запросы, и разработать ИС на основе спроектированной базы данных.
